# Ícones PWA

Para gerar os ícones PWA, você pode:

1. **Usar um gerador online**: Acesse https://realfavicongenerator.net/ ou https://www.pwabuilder.com/imageGenerator
2. **Criar manualmente**: Use um editor de imagens para criar:
   - `pwa-192x192.png` (192x192 pixels)
   - `pwa-512x512.png` (512x512 pixels)
   - `apple-touch-icon.png` (180x180 pixels)

Os ícones devem ter:
- Fundo: #1677ff (azul)
- Ícone: 📊 ou logo da aplicação em branco
- Formato: PNG com transparência (se necessário)

## Ícones mínimos (placeholder)

Por enquanto, você pode usar ícones simples. O PWA funcionará mesmo sem os ícones, mas é recomendado adicioná-los para melhor experiência do usuário.
